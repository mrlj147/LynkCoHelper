# 每日密钥刷新已迁移

自 2026-10-21 起，自动 AppSecret 提取和 VM 102 接收程序统一维护在私有仓库 `mrlj147/lynkco-build`。本公开仓库的每日发布工作流已退役，不再创建 `appsecret-latest` Release，也不公开发布密钥或加密密钥包。

新流程仍每日北京时间 00:37 调度，依据官方版本、APK SHA-256 和动态密钥类定位提取。提取结果仅以 RSA-OAEP + AES-GCM 加密形式存入私有 Actions artifact，保留三天；明文临时文件始终清理，密钥不提交到代码或 Docker 镜像。

VM 每十五分钟用仅对私有仓库具有 Actions 只读权限的凭据接收，验证来源 run/commit、接收者、完整性和有效期后更新原生 AppKey/AppSecret。账号、设备、通知、模型配置和业务任务计划保留。读取或解密失败时保留现有密钥。

维护文档和新工作流入口位于私有仓库的 `tools/appsecret/README.md` 与 `.github/workflows/refresh-appsecret.yml`。旧公开 Release 下载地址已停用。请勿将私钥、读取凭据、账号配置或解密结果提交到 GitHub。
